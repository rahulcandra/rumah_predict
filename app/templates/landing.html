Alur Analisis Machine Learning

Dari data mentah hingga prediksi real-time — proses saintifik yang transparan dan terstruktur.

1
Data Understanding

Dataset berisi 12.500 data properti dengan 9 fitur: luas tanah, luas bangunan, kamar tidur, kamar mandi, garasi, lantai, lokasi (20 kota), kondisi, dan sertifikat. Target: harga rumah (regresi).

Supervised Learning
2
Preprocessing

Fitur numerik distandardisasi dengan StandardScaler. Fitur kategorikal (Lokasi, Kondisi, Sertifikat) dienkode dengan OneHotEncoder. Split data: 80% training, 20% testing.

Pipeline sklearn
3
Pemodelan — Random Forest

Algoritma Random Forest Regressor dengan 200 pohon keputusan, max_depth=20, min_samples_leaf=3. Ensemble method ini unggul untuk data dengan fitur non-linear dan nilai outlier.

200 Decision Trees
4
Evaluasi Model

Model dievaluasi dengan MAE, RMSE, dan R² Score pada data test. R² = 0.9288 menunjukkan 92.88% variansi harga berhasil dijelaskan oleh model — performa sangat baik.

R² = 0.9288
5
Dashboard Analitik

Visualisasi interaktif: distribusi harga, feature importance, grafik aktual vs prediksi, dan harga median per kota — semua tersaji dalam dashboard yang bersih dan informatif.

4 Chart Interaktif

Prediksi Real-time

Input spesifikasi properti melalui form web, model Flask memanggil pipeline secara langsung dan mengembalikan estimasi harga dalam milidetik tanpa reload halaman.
